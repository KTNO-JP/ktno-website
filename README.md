# KTNO Website

メインコピー：**やってみよう！を仕事にする。**

KTNO Web Starterの第1号実装。白〜淡色の余白、巨大なKTNO、流体グラデーション、4領域のSERVICE、WORKS、CONTACTを実装。

Build: `npm run build` / Publish: `dist` / Branch: `main`

お問い合わせはNetlify Forms。フォーム検出・受信確認後に運用開始。実績写真と事例リンクは未提供のため、文字と図形で構成。架空の連絡先・URLは追加しない。

独自ドメイン設定は `SITE_URL`。Netlify productionのみindex可能。Search Consoleは公開後に実施。

TenkaHita/tenka-websiteは変更対象外。
