# 公開前後チェック
案件名：／確認日：／担当：／コミットSHA：／Deploy ID：／公開URL：

## 公開前
- [ ] 対象Organization・リポジトリ・Netlifyチーム確認
- [ ] デザイン・素材・文章・掲載許可・連絡先確認
- [ ] バックアップ／直前コミット記録
- [ ] build/check成功、GitHub Actions成功
- [ ] 360px／768px／1440pxの実ブラウザ表示、文字切れ・横スクロールなし
- [ ] メニュー、キーボード操作、画像、電話・地図・LINE・SNS・リンク確認
- [ ] title/description/OGP/canonical、画像alt確認
- [ ] お問い合わせを使う場合、個人情報の扱い・Forms検出・テスト送信・通知先確認
- [ ] 公開情報確定後にindexingEnabledをtrueへ変更（問い合わせ設定とは独立）

## 公開後
- [ ] mainの更新がNetlifyへ自動反映／Deploy成功
- [ ] 実際の公開URLのHTTP 200、CSS/JS/画像、コンソールエラーなし
- [ ] スマホ・タブレット・PCで主要導線を再確認
- [ ] 独自ドメインDNS・HTTPS・www統一リダイレクト確認
- [ ] SITE_URLが最終HTTPS URL、canonical・sitemapのURL一致
- [ ] robots.txtが本番でAllow、プレビューでDisallow
- [ ] Search Console所有権確認、sitemap送信、URL検査、登録リクエスト
- [ ] Google処理待ち／登録済みの区別を記録
- [ ] 後日の検索反映確認日を記録
- [ ] 変更履歴・不具合・原因・修正・再発防止記録

## 差し戻し
直前の正常コミット／Deployを復元し、公開URLで再確認する。原因修正は別コミットで残す。
