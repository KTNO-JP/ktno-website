# GitHub → Netlify → 独自ドメイン → SEO / Search Console
1. 案件リポジトリを作成しmainへコミット。GitHub Actionsの成功を確認。
2. NetlifyでImport from Git、対象Organizationとリポジトリを選択。main、build `npm run build && npm run check`、publish `dist`。既存の天花プロジェクトへ上書きしない。
3. 自動デプロイを有効にし、コミットSHAとDeployを照合。プレビューで表示と導線を確認。
4. 独自ドメインを登録済みならCustom domainへ追加。Netlifyの画面に表示されたDNS値を管理会社へ設定。既存のメール用MX/TXTを消さない。費用のある取得・更新は本人へ引き継ぐ。
5. DNS反映、HTTPS証明書、主要ドメイン・wwwの統一を確認。`SITE_URL`を最終HTTPS originへ設定して再デプロイ。
6. 公開情報確定後、`indexingEnabled: true`へ。title・description・canonical・OGP画像・構造化データ・robots.txt・sitemap.xmlを確認。
7. Search ConsoleのDomain property（DNS TXT）またはURL-prefix propertyで所有権確認。DNS値は画面から取得し、推測しない。
8. sitemap.xml送信 → URL検査 → インデックス登録リクエスト。Google処理待ちを記録。検索結果への掲載は別日に確認し、掲載日程や順位を保証しない。
9. 公開URL、ドメイン、コミットSHA、Deploy ID、検査結果を運用記録へ残す。
